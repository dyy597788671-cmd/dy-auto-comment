## 日常启动

在B电脑启动网页工具后台，保持影刀手机管理器与连接开启，从影刀主流程第1行启动一次。常驻配置下，无任务时等待，有网页新任务时自动领取；每条任务不必再次点击运行。手动停止或电脑重启后重新启动。

三种时间分别配置：网页预约时间默认0；主流程第11行是空闲检查间隔；每台设备完成后的冷却在 `config/settings.json` 配置。冷却缺少配置文件时默认随机300～600秒。

# B电脑：块7代码升级

本轮代码已经配套整理。现在完成安装；随后配置块8影刀卡片，全部接齐后再运行主流程。

## 本包完成的代码内容

| 项目 | 更新后的行为 |
| --- | --- |
| 当前设备数量 | 页面打开、提交时分别读取影刀已有连接状态；按提交时的最新总数拦截超量输入 |
| 时间 | 默认0；留空也按0；原有时间调度保留 |
| 断点续发 | 保留设备、评论、原互动计划和已保存的动作；只执行剩余动作 |
| 异常结束 | 保存失败和原错误，释放业务占用；其余可执行任务继续 |
| 连续调度 | 当前条目的本轮可执行设备结束后，继续下一条；设备不足的新任务保留原数量 |
| 网页入表 | 空闲时立即追加；正在发布或表格占用时暂存，工具后台在解除后自动追加 |
| 网页续发 | 支持续发整条未完成设备、指定设备；成功设备不重做 |
| 升级 | 修正已安装就跳过；保留B数据、应用编号、模块路径和已有元素 |

保持原网页工具和影刀工程。已验证的元素无需因本次代码升级重新匹配。

## 安装步骤：本块一次完成

1. 在B电脑停止影刀运行，随后完全退出影刀。关闭Excel/WPS中的任务表，关闭原网页工具的后台窗口。
2. 下载并解压 `DouyinTaskTool_v1.1.0_B.zip`。进入解压后的 `DouyinTaskTool_v1.1.0_B` 文件夹。
3. 双击这个新文件夹中的 `Start-Tool.cmd`。使用包内默认B路径即可，不需要自行编辑Python。
4. 若Windows询问是否允许局域网放行，按既有工具方式允许。已有防火墙规则会复用。
5. 等待窗口完成Python检查、代码更新、原生签名检查及网页启动。应看到 `VERSION=1.1.0`、`RESULT=TOOL_UPDATED`，签名为 `RESULT=REPAIRED` 或 `RESULT=ALREADY_VALID`，最后显示本机HTTP检查通过。重复安装显示 `ALREADY_CURRENT` 属正常。
6. 页面会自动打开。B本机管理地址为 `http://127.0.0.1:8765`；其它电脑使用本次窗口打印的实际局域网地址。以本次实际地址为准。
7. 保持工具后台窗口开启。重新打开影刀，只进入编辑器配置下一块；先不运行主流程。

更新直接替换代码，不创建备份，不更名旧文件。任务表、runtime_state、SQLite提交历史、评论分配、既有执行数据和日志保留；本包没有旧任务表或状态文件，不会用历史快照覆盖B当前数据。无需手动清理记录。

## 安装遇到报错

- 若提示影刀或原网页仍运行，关闭对应程序后重新双击同一入口。
- 若出现原始报错或没有HTTP检查通过，保持窗口内容，将整段报错一次发来。不要删除任务或运行记录；重复运行安装器可接续尚未完成的文件更新。
- 签名处理沿用此前B验证过的Runtime方法，已去掉备份步骤。本环境没有Windows Runtime，最终签名结果以B窗口输出为准。

## 后续块8的代码接口已准备好

影刀仍需接入以下四部分。代码安装本身不会修改可视化卡片。

1. APP启动和原等待后，复制既有7行“回首页——推荐”循环作为启动初始化。
2. 四项动作记录调用传入 `task_data`，`executed_actions` 初值取 `task_data.get("action_results", [])`；既有 `prepare_interactions(task_data)` 返回剩余动作。
3. 主流程的任务外层捕获调用 `finish_device_error`，使用主流程当前设备绑定和Task_ID，不依赖子流程局部变量。
4. 主流程启动一次调用 `start_execution(connection_infos)`；外层循环调用 `prepare_devices(connection_infos)`，空列表退出，非空列表按原方式顺序调用子流程。

已有 `主流程.txt` 是10行、`子流程1.txt` 是193行的历史名称清单；不包含卡片参数，也不能证明B后来调整后的准确行号。块8完整操作说明须按B实际对应位置给出，不能把这些历史行号写成当前已核实结果。

## 最后在B集中验证

全部卡片接齐后，一次验证并反馈：

1. 打开网页，显示的连接总数与影刀手机管理器一致；连接数量变化后再提交，按提交时最新数量判断。超量输入提示“当前连接设备总数：X台；本条设备数量：Y台，超过总数，请调整。”且不生成任务。
2. 空闲提交立即出现在实际 `data\task_cases.xlsx` 最后一个任务后。发布中或表格占用时提交暂存，空闲后无需重新提交就自动追加。
3. APP从非推荐页启动能复用原回退段回到推荐页；从推荐页直接继续。
4. 部分动作成功后异常，续发只做剩余动作；成功设备不重做，各项成功计数不重复累计。
5. 同一条目多设备及多个条目依次继续；一台设备报错后，其余可执行任务继续。

影刀自己的连接状态文件是否及时更新，以及手机内部ID占用的原始错误类型，尚未由当前上传快照证实；不能把代码测试当成这两项已通过。
